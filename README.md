# kimtaeho-dev.github.io

김태호 이력서 페이지입니다. https://kimtaeho-dev.github.io

빌드 없이 `index.html` 한 장으로 동작하는 정적 페이지입니다.

## 구성

- `index.html`: 이력서 본문과 스타일
- `assets/`: 프로필 사진, 파비콘, 링크 미리보기 이미지(og.jpg)
- `fonts/`: Pretendard Variable (dynamic subset), SIL Open Font License 1.1

## 수정

`index.html`을 직접 고친 뒤 `main`에 push하면 GitHub Pages에 반영됩니다.
브라우저에서 인쇄하면 밝은 배경의 인쇄용 레이아웃으로 바뀌어 PDF로 저장할 수 있습니다.
